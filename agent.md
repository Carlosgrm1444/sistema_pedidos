# Guía del agente

Este repositorio contiene el proyecto académico `sistema_pedido` del Grupo 5.

## Forma de trabajo

- Mantener el código comprensible para todos los integrantes.
- Implementar solamente la etapa solicitada por el profesor.
- Evitar agregar dependencias, arquitectura o funcionalidades no acordadas.
- Explicar en español las decisiones que el equipo deba comprender.
- Ejecutar `flutter analyze` y `flutter test` antes de integrar cambios.

Consulta también `context.md`, `task.md`, `memory.md` y `skills.md` antes de
realizar cambios relevantes.
