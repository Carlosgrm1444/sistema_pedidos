# Memoria del proyecto

## Decisiones vigentes

- El paquete Flutter se llama `sistema_pedido`.
- El repositorio remoto se llama `sistema_pedidos`.
- Las ramas de trabajo son `carlos`, `memo` y `meño`.
- `main` se reserva para cambios integrados y revisados.
- La aplicación usa una colección en memoria; todavía no incorpora una base de
  datos.
- La interfaz integra acceso, registro temporal y formación de pedidos.
