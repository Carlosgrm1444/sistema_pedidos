# Contexto

## Proyecto

Aplicación académica de Flutter para un sistema de pedidos. En etapas futuras
permitirá registrar productos, seleccionarlos para formar un pedido, manejar
cantidades y calcular el total.

## Curso

- Materia: Desarrollo de Aplicaciones Móviles.
- Unidad: 2.
- Equipo: Grupo 5, tres alumnos.
- Entrega actual: Práctica de Flutter, Etapa 1 - Interfaz.
- Fecha límite informada: 30 de septiembre de 2026 a las 00:59.

## Restricciones actuales

- No se requiere base de datos.
- No se desarrollará toda la aplicación en la primera etapa.
- Todos los integrantes deben poder explicar y modificar el código.
- La interfaz actual incluye acceso, registro temporal y captura de productos
  para formar un pedido con cantidades y total.

## Tecnología

- Flutter 3.41.5.
- Dart 3.11.3.
- Sin backend ni contenedores en esta etapa.
